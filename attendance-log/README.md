# Attendance Log

Приложение для ведения учёта посещаемости: группы, студенты, расписание пар, пометка присутствующих. Angular 22 + Firebase (Auth + Firestore) + Angular Material.

## Функциональность

- **Главная страница** (доступна всем):
  - селектор группы (вверху по центру);
  - календарь по месяцам (по умолчанию — текущий месяц);
  - кнопки режимов: **«Пометить учтёнными»** и **«Пометить перенесёнными в бумажный журнал»** (взаимоисключающие; при активном режиме появляется кнопка **«Отметить все»**);
  - чекбокс **«Суббота — учебный день»** (по умолчанию включён, хранится на группу/месяц в Firestore, 96 записей = 8 лет).
- **Визуальные состояния дней**:
  - прошедший день: красная рамка если не учтён, зелёная — если учтён;
  - воскресенье (и суббота при выключенном чекбоксе) — неактивное, бледное, с диагональными прочерками;
  - иконка бумажного листа при флаге "перенесено в бумажный журнал".
- **Страница дня**: таблица «студенты × пары (8:30, 10:15, 12:10, 14:00, 15:45)», клик по ячейке ставит галочку. Для авторизованных ячейки кликабельны; в tooltip отображается кто и когда отметил.
- **Права доступа**: неавторизованные — только просмотр; авторизованные — полное редактирование.
- **Тема**: светлая/тёмная, переключатель в шапке, хранится в localStorage.

## Настройка Firebase

1. Создайте проект в [Firebase Console](https://console.firebase.google.com).
2. Включите **Authentication** → метод **Email/Password**.
3. Включите **Firestore Database**.
4. Скопируйте конфигурацию приложения (Web) в `src/app/core/firebase.config.ts`:

```ts
export const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: 'YOUR_SENDER_ID',
  appId: 'YOUR_APP_ID',
};
```

5. Опубликуйте правила безопасности из файла `firestore.rules` (чтение — всем, запись — только авторизованным).

## Требуемые индексы Firestore

Для запроса дней месяца по группе нужен составной индекс в Firestore:

- Коллекция `scheduleDays`
- Поля: `studentGroupId` (ASC) + `date` (ASC)

Firestore сам предложит создать его при первом запросе (ссылка в консоли при ошибке «requires an index»).
